# Vendore Remote SSH

Secure SSH access to Vendore servers using Cloudflare Tunnel.

---

## Install

Linux / macOS

```bash
curl -fsSL https://raw.githubusercontent.com/semmozhiyan-dev/vendore-ssh/main/setup.sh | bash
```

or

```bash
wget -qO- https://raw.githubusercontent.com/semmozhiyan-dev/vendore-ssh/main/setup.sh | bash
```

---

## Connect

```bash
ssh semmozhiyan@server.vendore.tech
```

---

## Remove

```bash
curl -fsSL https://raw.githubusercontent.com/semmozhiyan-dev/vendore-ssh/main/uninstall.sh | bash
```
